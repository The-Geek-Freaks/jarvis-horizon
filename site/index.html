For installation, you need an OpenClaw Gateway you operate, device pairing and a realtime provider for Talk. Explore the demo without any of them.

Android

An ARM phone, tablet or modified display running Android 8.1 or later. Start with the signed alpha APK and the pairing guide.

Install on Android ↗Stock Echo firmware cannot install this APK. Public updates are manual.

Raspberry Pi 4

A display or mirror kiosk on 64-bit DietPi/Debian. Add a microphone and configure the audio output for your room.
